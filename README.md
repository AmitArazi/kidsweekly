# KidsWeekly

אפליקציית PWA פשוטה לניהול סידור שבועי לילדים וליצירת הודעת WhatsApp מעוצבת.

## יכולות

- בחירת מי לוקח ומי מחזיר בכל יום
- תאריכי השבוע אוטומטיים
- שמירה מקומית לכל שבוע
- הודעת WhatsApp מעוצבת עם אימוג׳ים
- העתקה ושיתוף ישיר
- התקנה כ-PWA ועבודה גם ללא אינטרנט

## הפעלה מקומית

יש להגיש את התיקייה דרך שרת מקומי, לדוגמה:

```bash
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000`.
